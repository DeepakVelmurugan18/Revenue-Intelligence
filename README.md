# SpendNest Revenue Intelligence Inbox

A modern, evidence-first Revenue Intelligence Inbox and Manager Workspace engineered for sales and customer success leadership. It disambiguates noisy telephony and calendar records, highlights verifiable coaching and deal signals, and handles late-arriving transcripts with full idempotent replay and manual override preservation.

Please see the complete documentation and startup instructions in [`candidate/README.md`](candidate/README.md) or launch the application directly:
- **Clickable Application:** Open [`candidate/app/index.html`](candidate/app/index.html) in any web browser.
- **5-Slide Executive Presentation:** Open [`candidate/slides/index.html`](candidate/slides/index.html).
- **Export Package & Manifests:** Located in [`candidate/exports/`](candidate/exports/).

---

## 🚀 Quick Launch

Open `candidate/app/index.html` in your browser, or start a local server:
```bash
npx serve candidate/app
# OR
cd candidate/app && python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000).
